# Vyndor Agent Documentation

## Installation

1. Open Home Assistant.
2. Go to Settings → Add-ons → Add-on Store.
3. Add this repository:

   https://github.com/Valcked/vyndor-home-assistant-addons

4. Install Vyndor Agent.
5. Copy the installation ID and installation token from Vyndor Control.
6. Paste them in the add-on configuration.
7. Start the add-on.

## Security

Install the Vyndor Agent only on Home Assistant installations that you own or manage.

The installation token should be generated by Vyndor Control and should not be shared publicly.
